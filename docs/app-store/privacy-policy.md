# Privacy Policy

Effective date: 2026-09-05

MicFirst is a local macOS menu bar utility for managing the system
default audio input device.

## Data Collection

MicFirst does not collect, store, transmit, sell, or share personal
data.

The app does not include analytics, advertising, tracking, accounts, telemetry,
or third-party SDKs.

## Local Settings

MicFirst remembers discovered input devices (identifiers, names, icon
and connection metadata), their priority order, manual menu visibility, disconnect
timestamps, and the automatic-input setting
locally using `UserDefaults`. Offline devices remain remembered until removed
from the app's device list. This information is not transmitted off the Mac.

## Network Access

MicFirst does not make network requests.
